# Application Screenshots Guide

This directory holds visual demonstration screenshots for project submissions and report documentation.

## Suggested Screenshots

1. **`01_dashboard.png`**  
   The analytics dashboard showing total saved programs, total compilation attempts, success rate metric, and recent history table.

2. **`02_code_analyzer_success.png`**  
   The code editor showing a successful compilation with status banner, token count, execution duration, and tabbed outputs.

3. **`03_syntax_tree_ast.png`**  
   The AST visualization tab showing the hierarchical representation of statements and arithmetic expressions.

4. **`04_intermediate_code_tac.png`**  
   The Three-Address Code generation tab showing generated temporary variables (`t1`, `t2`, ...) and the download button.

5. **`05_error_diagnostics.png`**  
   The error report tab demonstrating detection of missing semicolons, unmatched parentheses, or semantic errors with line/column coordinates and suggestions.

6. **`06_token_analysis.png`**  
   The token inspection table with category filters and category breakdown charts.

7. **`07_compilation_history.png`**  
   The historical audit log showing past compilations with status filters and deep run inspection.

8. **`08_saved_programs.png`**  
   The saved programs manager showing search, rename, and load actions.

---
*Note: To capture screenshots, launch the application via `streamlit run app.py` and take screen captures on your browser.*
